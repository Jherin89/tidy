The first public release of **tidy**, a safe, rules-driven organizer for a messy Downloads folder.

![tidy demo](https://raw.githubusercontent.com/Jherin89/tidy/v0.1.0/docs/demo.gif)

### Highlights

- **Dry run by default.** `tidy` prints a preview table (file → rule → action → destination → size) and changes nothing. `tidy --apply` carries it out.
- **Rules in plain TOML** that match on extension, file-name glob, age (`older_than = "30d"`), and size (`larger_than = "100MB"`). The first match wins. Actions are *move* (anywhere, `~` expanded, optional `YYYY-MM` folders) or *trash*.
- **Sensible built-in rules** (screenshots, PDFs, images, video, audio, spreadsheets, documents, ebooks, old archives, and installers older than 30 days → Trash). `tidy init` writes them out for editing.
- **Safe by design:** uses the system Trash and never permanently deletes, never overwrites (`name (1).ext`), and skips partial downloads, hidden files, folders, and symlinks.
- **`tidy undo`** reverses the last run from a JSON log, including removing the folders it created if they're empty.
- **`tidy watch`** sorts new downloads automatically once they finish.
- `--json` output, `--older-than`, `tidy rules`, and clear errors with nonzero exit codes.

### Install (macOS, Apple Silicon)

```bash
tar -xzf tidy-0.1.0-aarch64-apple-darwin.tar.gz
xattr -d com.apple.quarantine tidy-0.1.0-aarch64-apple-darwin/tidy
mkdir -p ~/.local/bin && mv tidy-0.1.0-aarch64-apple-darwin/tidy ~/.local/bin/
tidy --version
```

Or build from source on any platform: `cargo install --git https://github.com/Jherin89/tidy`

See the [step-by-step setup and usage guide](https://github.com/Jherin89/tidy#setup-guide-step-by-step).

### Known limitations

- On macOS, `tidy undo` can't pull trashed files back out of the Trash automatically. It lists them so you can use Finder's **Put Back**. Moved files are restored automatically.
- The binary is not notarized, so remove the quarantine flag as shown above.
- Prebuilt binaries are Apple Silicon only. Intel Macs, Linux, and Windows can install with `cargo install`.
